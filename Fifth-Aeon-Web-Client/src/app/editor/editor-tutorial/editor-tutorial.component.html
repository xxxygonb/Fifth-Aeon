卡牌添加教程

本教程面向想自制卡牌的玩家。读完你就能用编辑器拼出一张完整的卡牌；想深入机制开发时，可参考项目中的 docs/CARD_CREATION_GUIDE_CN.md。

四、四种卡牌类型

类型特有属性说明
单位 Unit攻击力 / 生命 / 种族场上作战主力，最多数量受卡组规则限制
法术 Spell—打出即结算，无实体留场
附魔 Enchantment力量 / 充能费用挂在场上持续生效，力量可被双方增减（博弈点）
物品 Item攻击加成 / 生命加成 / 装备目标装备给某个单位，随单位存亡

五、种族 UnitType

共 21 种：人形（人类/牧师/士兵/邪教徒/密探/吸血鬼）、自然（狼/蜘蛛/蛇/猛兽/昆虫/飞鸟/巨龙）、异类（怪物/恶魔/元素/亡灵）、机械（机械偶/建筑/载具）等。 种族会被「指定种族目标器」「统领光环」「入场协同」等机制引用； 机械偶/建筑/载具属于机械体——免疫中毒与催眠，且不被“生物限定”效果选中。

九、效果文本是怎么生成的

你不需要手写效果描述——文本由机制列表自动拼装。以“狼崽”为例：

new BuffTarget(0, 1)           ← 效果：给目标 +0/+1
   .setTrigger(new Affinity()) ← 时机：首次召唤同种族单位时
（目标器 SelfTarget）          ← 对象：此单位

生成描述：「共鸣：令此单位获得 0/+1。」触发一次后，该句会以灰色显示表示已失效。

文本中的两种特殊标记（机制源码里使用，编辑器无需手写）：

标记用途
[dynamic](n)[/dynamic]随局面变化的数值（如墓地单位数），渲染为高亮数字
[depleted]X[/depleted]触发后已失效的段落，渲染为灰色

十、实战流程与自查

步骤操作
1编辑器列表页点 ➕ 新建卡牌
2填名称、类型、费用、属性（注意阵营需求总和 ≤ 6）
3「现有机制」搜索添加效果，逐条设置触发时机、目标、参数
4看右侧「卡牌预览」的效果文本是否符合预期（文本由机制自动生成）
5保存后开一局 AI 对局实测；卡牌 ID 保持唯一且不再修改

十一、常见问题

问题解答
多个机制的执行顺序？列表从上到下依次结算，用 ↑↓ 按钮调整
「沿用卡牌自身的目标」是什么？该效果使用卡牌打出时指定的目标（卡牌左上目标器），例如“对一个敌方单位造成伤害”的法术
阵营需求为什么加不满？四项需求总和上限 6 点（界面限制），超出部分会被拦截
卡牌重名会怎样？内部 ID 唯一即可正常游玩；但为避免翻译与检索混乱，建议名称不重复
想要全新的效果？需要开发新机制（TypeScript）。进阶指引见项目 docs/CARD_CREATION_GUIDE_CN.md 第 10 节：机制继承体系、事件系统与自定义关键词
给单位加“飞行”这样的关键词？直接在机制里添加 Flying 等被动机制；或用「授予能力」把关键词给别的单位
